# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-07-10

### Added

- System DNS, DNS/UDP, DNS/TCP, and DNS-over-HTTPS comparison.
- Pinned-IP TCP, TLS/SNI, fragmented SNI, TLS 1.2/1.3, and certificate probes.
- Plain HTTP Host fragmentation and bounded response fingerprints.
- Dependency-free QUIC Version Negotiation probe over UDP/443.
- Cross-platform traceroute parsing for Windows, Linux, and macOS.
- Evidence-based findings and exact endpoint direct/VPN report comparison.
- Safe managed VPN route files containing destination `/32` and `/128` entries.
- Stable JSON schema for AI-agent operation.
